# Diagramas de la guía web

Copias **exactas** de los 31 bloques PlantUML del Anexo A de `INSTRUCCIONES-WEB.md` (raíz del
repositorio). `INSTRUCCIONES-WEB.md` cita cada uno de estos archivos con su ruta completa.

- Son la versión **para quien construye el back y el front**: llevan rutas de la API y códigos de
  error, a diferencia de los `.puml` de `diagramas/` y `diagramas/puml/`, que son los del documento
  y están en lenguaje natural.
- Si cambias un diagrama aquí, cambia también su bloque en el Anexo A (y al revés).
